# 💅 Nails

אפליקציה למציאת מניקוריסטיות קרובות אלייך.

- **הרשמה חובה:** כל משתמשת נרשמת עם Google או עם אימייל וסיסמה (שתי השיטות בחינם). מי שכבר יש לה חשבון ומנסה להירשם שוב עם אותו מייל, עוברת לעמוד ההתחברות עם המייל כבר ממולא.
- **בעלת עסק** מעלה את העסק שלה: שם, טלפון, עיר, מיקום על המפה, הטיפולים שהיא עושה, **טווח מחירים** (החל מ-___ עד ___ ₪), **שעות פעילות** (אילו ימים ובאילו שעות) ו**לפחות 5 תמונות** של עבודות.
- **לקוחה** בוחרת רדיוס (2 / 5 / 10 / 25 / 50 ק"מ) מהמיקום שלה או בוחרת עיר, ורואה את העסקים מהקרוב לרחוק, עם טווח המחירים ו"פתוח עכשיו / סגור" על כל כרטיס.
- **כפתור וואטסאפ** פותח שיחה עם העסק עם הודעה מוכנה: "היי! הגעתי אלייך דרך אפליקציית Nails 💅"
  כל לחיצה נספרת, כך שבעלת העסק רואה כמה פניות הגיעו מהאפליקציה.

## מה יש באפליקציה

| מסך | מה עושים בו |
|------|-----|
| הרשמה / התחברות | Google, אימייל וסיסמה (כולל "שכחתי סיסמה") |
| בית | חיפוש לפי שם/עיר, רדיוס, עסקים לפי מרחק |
| עמוד עסק | גלריית תמונות, מרחק, טווח מחירים, שעות פעילות, וואטסאפ / חיוג / ניווט ב-Waze |
| הוספת עסק (+) | טופס: פרטים ומחירים ← שעות פעילות ← כתובת מלאה (עיר, רחוב, מספר, כניסה ודירה לא חובה), או "אני בעסק עכשיו" מהטלפון ← תמונות (5–12). המיקום על המפה נמצא מהכתובת דרך OpenStreetMap (Nominatim) |
| פרופיל | הפרטים שלי, העסקים שלי עם סטטיסטיקות (צפיות, פניות בוואטסאפ), עריכה, התנתקות |
| שיתוף עסק | כפתור שיתוף בעמוד העסק: וואטסאפ, העתקת קישור, או שיתוף מהטלפון. מי שפותחת קישור בלי להיות מחוברת, מגיעה לעסק מיד אחרי ההרשמה |
| אינסטגרם | שדה לא חובה לבעלת העסק (@שם, שם או קישור), וכפתור "אינסטגרם" בעמוד העסק |
| תמונה ראשית | ⭐ על תמונה הופך אותה לראשונה, והיא מופיעה בכרטיס העסק |
| התקנה כאפליקציה | אייקון, manifest ו-service worker. באנדרואיד מופיע באנר "התקנה", באייפון הסבר איך מוסיפים למסך הבית. בלי אינטרנט נפתח עמוד "אין חיבור" |
| מועדפים | עסקים ששמרת עם הלב, שמורים בחשבון (בכל מכשיר). כשעסק שמור מעלה תמונות חדשות מופיע סימון "תמונות חדשות" ונקודה על הלשונית. בעלת העסק רואה כמה שמרו אותו |
| אימות בעלת עסק | בעלת עסק שולחת סלפי מהמצלמה. אחרי אישור מופיע ✓ ליד העסקים שלה. הסלפי נשמר בתיקייה פרטית ונמחק אחרי ההחלטה |
| ניהול | רק לחשבונות שמוגדרים ב-`NAILS_ADMIN_EMAILS`: בקשות אימות ממתינות, אישור/דחייה עם סיבה, ביטול אימות |
| הגדרות ומידע | עריכת פרופיל (כולל שינוי סיסמה), אודות, יצירת קשר (טלפון/וואטסאפ), תנאי שימוש, מדיניות פרטיות, הצהרת נגישות, מחיקת חשבון |

כל עסק שייך לחשבון של מי שהעלתה אותו, ורק היא יכולה לערוך או למחוק אותו, מכל מכשיר שהיא מחוברת בו.

## הגדרת ההתחברות (Firebase)

את ההתחברות מנהל **Firebase Authentication** של Google. כרגע פעילות רק שתי שיטות חינמיות: **Google** ו**אימייל + סיסמה**.

1. נכנסים ל-https://console.firebase.google.com ויוצרים פרויקט חדש.
2. **Authentication → Sign-in method** ומפעילים:
   - **Google**: מפעילים ושומרים.
   - **Email/Password**: מפעילים ושומרים.
   - (Phone ו-Apple לא צריך להפעיל. הם עולים כסף ולכן כבויים באפליקציה.)
3. **Authentication → Settings → Authorized domains**: מוסיפים את הדומיין שבו האפליקציה תרוץ.
4. **Project settings → General → Your apps**: מוסיפים אפליקציית Web. הערכים שלה שמורים בקובץ `firebase-config.json` (פרויקט `nails-cb7e0`).
   אפשר לדרוס אותם במשתני סביבה: `FIREBASE_PROJECT_ID`, `FIREBASE_API_KEY`, `FIREBASE_AUTH_DOMAIN`, `FIREBASE_APP_ID`.

הערכים האלה ציבוריים (לא סודות). השרת בודק כל בקשה מול המפתחות של Google, כך שאי אפשר לזייף משתמשת.

### להוסיף בעתיד טלפון (SMS) או Apple

הקוד כבר מוכן. מספיק להפעיל אותם ב-Firebase ולהגדיר בשרת:
`NAILS_SIGNIN_METHODS=google,email,phone,apple`
- **Phone**: שליחת SMS דורשת לחבר אמצעי תשלום לפרויקט (תוכנית Blaze), וכל SMS עולה כסף.
- **Apple**: דורש חשבון Apple Developer בתשלום שנתי. אם האפליקציה תעלה ל-App Store, Apple מחייבת להציע אותו.

## הרצה מקומית

```bash
pip install -r requirements-dev.txt
NAILS_DEV_AUTH=1 uvicorn app.main:app --reload
# לפתוח את http://localhost:8000
```

`NAILS_DEV_AUTH=1` מאפשר לנסות את האפליקציה בלי Firebase, עם חשבונות לדוגמה. **אסור להפעיל את זה בשרת אמיתי.**

נתוני דוגמה (לא חובה): `pip install pillow && python scripts/seed_demo.py`

בדיקות: `pytest`

### תצוגה מקדימה בלי שרת

`python demo/build.py` בונה קובץ HTML אחד (`demo/nails-preview.html`) שרץ כולו בדפדפן: `demo/mock-api.js` עונה במקום השרת, עם עסקים לדוגמה, והנתונים נשמרים רק בדפדפן. משמש להצגת האפליקציה לפני שהיא עולה לשרת אמיתי.

## מבנה

```
app/main.py     השרת (FastAPI): משתמשות, חיפוש, הוספה, עריכה, שעות פעילות, וואטסאפ
app/auth.py     בדיקת ההתחברות (Firebase)
app/geo.py      חישוב מרחק, עיצוב מספר טלפון
app/db.py       מסד הנתונים (SQLite) ותיקיית התמונות
static/         האפליקציה עצמה (HTML/CSS/JS), מימין לשמאל, מותאמת לטלפון
tests/          בדיקות
```

הנתונים נשמרים בתיקייה `data/` (אפשר לשנות עם `NAILS_DATA`).

## פרטיות, אבטחה ונגישות

- **בלי מעקב:** אין עוגיות פרסום, פיקסלים או סטטיסטיקה של צד שלישי. הפונטים (Heebo, Frank Ruhl Libre, רישיון OFL) נשמרים בשרת (`static/fonts`). הגורם החיצוני היחיד הוא Firebase להתחברות.
- **כותרות אבטחה:** Content-Security-Policy (רק קבצים שלנו וגוגל-התחברות), nosniff, בלי הטמעה במסגרת, `no-store` ל-API. אפשר לכבות את ה-CSP עם `NAILS_CSP=off` אם ספק התחברות חדש צריך עוד דומיין.
- **הסכמה:** בהרשמה חובה לסמן הסכמה לתנאים ולפרטיות (נשמרים תאריך וגרסה, `TERMS_VERSION`). בהוספת עסק חובה לאשר שהתמונות שלה ושמותר לפרסם אותן.
- **עמודים משפטיים** (נגישים גם לפני הרשמה): תנאי שימוש, פרטיות, עוגיות ואחסון במכשיר, נגישות. פרטי המפעיל מוגדרים ב-`NAILS_OPERATOR_NAME`, `NAILS_OPERATOR_ID`, `NAILS_OPERATOR_ADDRESS`.
- **404:** עמוד שגיאה לכתובות שלא קיימות, גם בשרת וגם בתוך האפליקציה.
- **מינימום מידע:** בשרת להריץ את uvicorn עם `--no-access-log`, כדי שמיקום החיפוש (שנשלח בכתובת הבקשה) לא יישמר בלוגים.
- **נתוני דוגמה** (`scripts/seed_demo.py`) עובדים רק עם `NAILS_DEV_AUTH=1`, ולכן לא יכולים להגיע לשרת האמיתי.
