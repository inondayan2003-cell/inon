## 5. "הקוד של הערוץ" (`Clone` ב-`research/cryptonew84.py`)

```
בכל יום חול, בכל אחד משלושת החלונות, פעם אחת, בדקה אקראית:
    אם עברו פחות מ-2.5 שעות מהסיגנל הקודם → מדלגים
    תזוזה = מחיר עכשיו − מחיר הסיגנל הקודם (או לפני 4 שעות)
    אם |תזוזה| < 10$ → תזוזה = התנועה בשעה האחרונה
    כיוון = נגד התזוזה
    קצה קרוב = מחיר ∓ 1$ ; רוחב = 10$ אם זז ≥15$ ב-4 שעות, אחרת 5$
    TP1/2/3 = קצה קרוב ± 5/10/15 , TP4 = OPEN
    סטופ = קצה רחוק ∓ 10$  (בהודעה: SL⛔️#VIP)
```

`render()` מוציא את ההודעה בכל אחת משלוש התבניות שלהם (`aug`, `sep`, `product`).
`compare()` בודק, לכל אחד מ-105 הסיגנלים, איפה המחיר היה ברגע השליחה, איזו תנועה (15 דקות, שעה, 4 שעות, 24 שעות)
הכי מנבאת את הכיוון שלהם, ובכמה מהחלונות הקלון בחר באותו כיוון.
