# יומן התקדמות

## 23/11/2026: מיפוי ראשוני
- נוצר מבנה התיקיות 01-14.
- ניסיון לגשת ל-youtube.com מהסביבה נחסם. בקשה להוסיף את youtube.com לרשת הסביבה **נדחתה**.
- גם michastocks.app ו-podcasts.apple.com חסומים, ב-curl וב-WebFetch.
- חיפוש ברשת העלה: 2 פלייליסטים (האקדמיה, הבורסה), 2 סדרות ממוספרות חלקיות, כ-10 סרטונים בודדים רלוונטיים, פודקאסט ואתר.
- **נלמדו בפועל: 0 סרטונים.** לא נקרא אף תמליל.

## אפשרויות להמשך (דורשות החלטה שלך)
1. **לפתוח את www.youtube.com ברשת הסביבה.** אז אוכל להריץ yt-dlp (מותקן מ-PyPI, שזמין) כדי למשוך את רשימת הפלייליסטים המלאה ואת הכתוביות האוטומטיות בעברית של כל סרטון. זו הדרך המהירה והמלאה ביותר.
2. **מפתח YouTube Data API.** הדומיין www.googleapis.com פתוח. עם מפתח אפשר למשוך רשימות פלייליסטים וכותרות ותיאורים, אבל **לא** תמלילים.
3. **לספק תמלילים ידנית.** אתה מוריד אותם (למשל דרך "הצג תמליל" ביוטיוב) ושם אותם בתיקייה `transcripts/`.
4. **להריץ את הסשן על המחשב שלך** (Remote Control), שם יש גישה רגילה ל-YouTube.
