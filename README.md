# 🥇 אנליסט הזהב: בוט + Mini App בטלגרם

הבוט סורק את הזהב כל 2 עד 5 דקות ב-4 טווחי זמן ושולח התראה לטלגרם **ברגע שיש סיגנל לונג או שורט**.
כל התראה כוללת כניסה, סטופ ושני יעדים. אחר כך הבוט מעדכן כשהעסקה מגיעה ליעד 1, ליעד 2 או לסטופ.
ה-Mini App מציג את הניתוח המלא: ציון משוקלל, יישור טווחים, גרף, רמות מפתח וביצועי הסיגנלים.

## איך המערכת מחליטה

| טווח | משקל | תפקיד |
|------|------|-------|
| 4H | 30% | כיוון כללי |
| 1H | 30% | כיוון יומי |
| 15M | 25% | מבנה ומגמה |
| 5M | 15% | תזמון כניסה |

בכל טווח מחושב ציון בין 100- ל-100+ לפי: סדר ממוצעים נעים (EMA 21/50), מיקום מול EMA200, MACD, RSI, Supertrend ו-ADX/DMI.

**סיגנל נשלח רק כשכל התנאים מתקיימים:**
1. הציון המשוקלל ‎≥ 50 (לונג) או ‎≤ 50- (שורט).
2. 4H ו-1H לא נגד הכיוון, ו-15M תומך בכיוון (‎≥ 20).
3. ADX ב-15M ‎≥ 18, כלומר יש מגמה ולא דשדוש.
4. המחיר לא רחוק מדי מ-EMA21 ב-15M (עד 2 ATR), כדי לא לרדוף אחרי מהלך.
5. ה-5M באותו כיוון (תזמון).
6. לא נשלח סיגנל לאותו כיוון ב-45 הדקות האחרונות.

**ניהול העסקה:** סטופ = ‎1.5×ATR(15M) או מעבר לסווינג האחרון (בין השניים, עד 3 ATR לכל היותר).
יעד 1 = 1R: סוגרים חצי ומזיזים סטופ לכניסה. יעד 2 = 2R. עסקה שלא הסתיימה נסגרת אחרי 8 שעות.
כשהציון יורד מתחת ל-20 נשלחת התראת "הסיגנל נחלש".

## שיטה 2: נזילות (💧 SMC/ICT)

רצה במקביל לשיטת המגמה, עם עסקה משלה:
1. **רמות נזילות:** השיא והשפל של אתמול (יום מסחר מתחיל ב-17:00 ניו יורק), והשיא והשפל של סשן אסיה (עד 02:00 ניו יורק).
2. **סוויפ:** רק בשעות לונדון (02:00–05:00 ניו יורק) וניו יורק (07:00–11:00 ניו יורק), המחיר עובר רמה ולוקח את הסטופים. כל רמה נספרת פעם אחת ביום.
3. **שבירת מבנה:** תוך שעה המחיר חוזר מעבר לרמה ונסגר מעבר לשיא או השפל של 6 הנרות שלפני הסוויפ.
4. **FVG:** פער של 3 נרות בתנועה החדה. נשלחת **הזמנת לימיט באמצע ה-FVG**, בתוקף לשעה.
5. **סטופ:** מעבר לקצה הסוויפ. **יעד 1** = 1R, **יעד 2** = 2R, או הנזילות שבצד השני אם היא בטווח 2R–4R.
6. **מסנן:** לא נכנסים נגד מגמה חזקה ב-1H/4H.

## הקמה (פעם אחת, כ-15 דקות)

### 1. יצירת הבוט ב-BotFather
1. בטלגרם, פתח את **@BotFather** ושלח `/newbot`.
2. תן שם (למשל `Gold Analyzer`) ושם משתמש שמסתיים ב-`bot` (למשל `inon_gold_bot`).
3. BotFather ישלח לך **טוקן** בפורמט `123456789:AA...`. שמור אותו ואל תשתף אותו עם אף אחד.

זהו. את כפתור התפריט ואת הפקודות הבוט מגדיר לבד כשהשרת עולה.

### 2. מפתח נתונים (מומלץ, חינם)
הירשם ב-[twelvedata.com](https://twelvedata.com) והעתק את ה-API Key.
עם המפתח הבוט עובד על **XAU/USD ספוט**, כלומר אותו מחיר שאתה רואה אצל הברוקר.
בלי מפתח הבוט משתמש ב-Yahoo (GC=F, חוזה עתידי), שהמחיר שלו גבוה בכמה דולרים מהספוט.

### 3. העלאה לשרת משלך (Oracle Cloud או כל שרת לינוקס) ← מומלץ
1. ב-Oracle Console: **Networking → Virtual Cloud Networks → ה-VCN שלך → Security Lists → Default** ושם **Add Ingress Rules**:
   Source CIDR `0.0.0.0/0`, IP Protocol `TCP`, Destination Port Range `80,443`.
2. התחבר לשרת ב-SSH והרץ:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/inondayan2003-cell/inon/claude/telegram-stocks-gold-analyzer-akepc8/deploy/install.sh | sudo bash
   ```
   הסקריפט מתקין Docker, מבקש את הטוקן ואת המפתח, ומפעיל את הבוט עם HTTPS אוטומטי (כתובת בסגנון `https://1-2-3-4.sslip.io`).
3. לעדכון גרסה בעתיד, מריצים את אותה פקודה שוב.

### 3ב. חלופה: Render (חינם)
1. היכנס ל-[render.com](https://render.com) עם GitHub, ובחר **New → Blueprint** ואת ה-repo הזה (קובץ `render.yaml` מגדיר הכל).
2. מלא את המשתנים: `BOT_TOKEN` ו-`TWELVEDATA_API_KEY`.
3. אחרי שהשירות עולה, העתק את הכתובת שלו (למשל `https://gold-analyzer.onrender.com`), הגדר אותה ב-`WEBAPP_URL` ושמור.
4. **חשוב:** בתוכנית החינמית Render "מרדים" את השרת אחרי 15 דקות בלי תנועה, ואז לא יוצאות התראות.
   הפתרון: ב-[uptimerobot.com](https://uptimerobot.com) (חינם) צור מוניטור HTTP לכתובת `https://<הכתובת שלך>/health` כל 5 דקות.
   חלופה בלי הגבלה: תוכנית Starter ב-Render (7$ לחודש), שגם שומרת את היסטוריית העסקאות בין עדכוני גרסה.

### 4. התחלה
פתח את הבוט בטלגרם ושלח `/start`. מהרגע הזה ההתראות פעילות.
כדי שאף אחד אחר לא יוכל להשתמש בבוט: שלח לבוט הודעה כלשהי, ובהגדרת `ALLOWED_USER_IDS` שים את ה-ID שלך (אפשר לקבל אותו מ-@userinfobot).

## פקודות
- `/status`: הניתוח העדכני
- `/alerts_on` / `/alerts_off`: הפעלה והשתקה של התראות
- `/app`: פתיחת ה-Mini App
- `/backtest`: בדיקה היסטורית של השיטה על 6 החודשים האחרונים (נשלחת גם אוטומטית אחרי כל עדכון של השיטה)

## פיתוח מקומי
```bash
pip install -r requirements.txt pytest
python -m pytest            # בדיקות
python backtest.py          # בדיקה היסטורית על 60 הימים האחרונים
BOT_TOKEN=... uvicorn app.main:app --reload
```

## מבנה
```

app/service.py      לולאת הניתוח והתראות
app/bot.py          בוט טלגרם
app/main.py         שרת API + הגשת ה-Mini App

```
